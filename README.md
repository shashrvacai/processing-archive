# processing-archive

Nine years of Processing sketches, 660 of them, sorted by which ones kept getting copied. A sketch that got copied got played somewhere. The seek-and-arrive vehicle from November 2017 turned up at FHSE, then Jazz Fest, then Cyberia, then in 2025 it started spelling my name on the homepage. This is the folder, deduplicated, dated as well as I could manage, with the show versions kept because the upgrades are the story. Syphon got added the week before a gig every single time.

Written up, one lineage at a time, on [shashrvacai.com/blog](https://www.shashrvacai.com/blog). Each folder here is one lineage; each subfolder is one dated copy, named `YYYY-MM[-DD]_what_it_was`. Dates come from Processing's own `sketch_YYMMDD` file names, screenshots inside the folders, and the show they were built for. Filesystem dates were useless (two bulk copies), so where a folder says `undated`, it is.

More lineages land as the posts do: flow fields, the noise kit, circles and ripples, audio reactive, Kinect and webcam, physics, type, and the show rigs.

Everything here is Processing 3 (Java mode). Libraries used across the folder: processing.sound, oscP5, Syphon, Spout, SimpleOpenNI, PixelFlow, Box2D, toxiclibs, ControlP5, Geomerative. Not included in this repo.
