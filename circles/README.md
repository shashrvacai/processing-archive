# circles

Rings, ripples, dots in grids, things that spin. The sketches made when there was nothing to make, which turned out to be most evenings from early 2018 to the last week before the folder went quiet in February 2020.

Read the story: [Code 33: Going in circles](https://www.shashrvacai.com/blog/code-33-going-in-circles).

| Folder | Date | Where | What it is |
|---|---|---|---|
| 2017_circle_one, _two | 2017 | practice | the first two |
| 2018-01-28_hatch_circle_audio_kinect | Jan 2018 | practice | hatched circle, audio and Kinect |
| 2018-02-07_ring_flags (+ Ninth Node copy) | Feb 2018 | Ninth Node | a grid of small rings that lean toward the mouse |
| 2018-02-14_iron_and_magnet (+ Ninth Node copy) | Feb 2018 | Ninth Node | a checkerboard of bars that swing like filings |
| 2018-02_ripple_with_mask (+ Ninth Node, Jazz Fest q, Algorave copies) | Feb 2018 to 2019 | Ninth Node, Algorave | thirty concentric rings breathing to the mic. The most-copied circle |
| 2018-02_shifting_shadows (+ Ninth Node copy) | Feb 2018 | Ninth Node | stacks of rotating discs on an orange card |
| 2018-04-11_squigly_circle, jazzfest audio copy, random_circles | Apr to Jun 2018 | Jazz Fest | a noisy circle, then the audio version for the show |
| 2018-06-18_squish_circle_noise, _concentric_door | Jun 2018 | Squish | show copies |
| 2018-09-30_distorted_circle_audio | Sep 2018 | practice | a circle pulled by sound |
| 2019-04-28_polkadots, 2019-06-17_vortex, 2019-06-18_tenticular (+ Algorave, Cyberia), _nice_circle, 2019-08-06_random_circles | 2019 | practice, Cyberia | the year of spinning polygons and tentacles |
| undated_water_ripple, _kinect, _kinect_ripple | 2018 to 2019 | practice | the water ripple algorithm, then with a body dropping the stones |
| 2020-02-07_amaze_circle, 2020-02-10_noise_vortex, _delaunay | Feb 2020 | practice | the last week |
| undated_circle_packing | 2019 | practice | circle packing inside type |

Libraries: processing.sound, SimpleOpenNI. Data folders not included.
