# misc

Everything from the Processing folder that did not fit a lineage. Sorted the way the folder was sorted on disk, bucket names kept: `00-shows` is the show files that were not the shows in [shows/](../shows/), `03-illustrative` and `03-Engines` are the one-off sketches and the reusable bits, `08-type`, `10-arduino`, `13-Shaders` and the rest are what the name says. Mostly undated.

The recordings that lived next to these sketches, one video with chapters: [processing archive misc](https://youtu.be/bwDF6mEGENg).

Same deal as the rest of the repo: Processing 3, Java mode, libraries not included. All code by Cai.
