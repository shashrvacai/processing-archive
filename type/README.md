# type

Letters that misbehave. Most of this folder is me working through Amnon Owed's Generative Typography examples with Geomerative, then bending them: a word scanned line by line, points connected inside a word, a "designer" grid, "Filament" as a plexus for the concert of the same name, text rain after Camille Utterback, and a genetic algorithm spelling its way to Shakespeare. The flow-field and aggregate-particle type pieces are here too (they also appear in flow-field and agents).

Read the story: [Code 14: Letters that misbehave](https://www.shashrvacai.com/blog/code-37-letters-that-misbehave).

| Folder | Date | What it is |
|---|---|---|
| 2018-05-16_using_geomerative | May 2018 | the first Geomerative test |
| 2018_jumbled_thoughts, 2018_scanning, 2018_connect_the_points | 2018 | Hello world jumbled; "Scanning" copied one row at a time; points inside a word joined by distance |
| 2018_text_rain, 2018_genetic_shakespeare | 2018 | after Utterback, after Shiffman |
| 2019_filament_plexus_text | 2019 | "Filament" as a plexus, for the Filament concert |
| 2019_ocean_lines, 2019_nature_particles | 2019 | lines climbing through a word; particles living inside it |
| 2019-06-15_aggregate_particles, 2019-06-15_designer_grid | Jun 2019 | particles aggregating into text; a grid over the word designer |

Libraries: Geomerative, processing.pdf. After Amnon Owed (CAN, 2014) throughout. The downloaded example set itself is not included.
